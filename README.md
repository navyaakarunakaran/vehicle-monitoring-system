# Vehicle Monitoring Dashboard (Demo)

A personal front-end demo of a vehicle entry/exit monitoring dashboard,
built with HTML, CSS and vanilla JavaScript.

> Built as a standalone demo with mock data. It contains no code or data
> from any employer or client project.

## Features
- Summary cards computed from the data (total, inside, completed, pending)
- Live search by plate number
- Filters by vehicle status and transaction status
- Status badges for ANPR detection and payment state
- Responsive layout

## Live demo
https://navyaakarunakaran.github.io/vehicle-monitoring-system/

## Run locally
Open `index.html` in a browser. No build step needed.
